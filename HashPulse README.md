# HashPulse — Sports Sentiment Intelligence

## 🚀 Track the Pulse of Sports Fans in Real Time

HashPulse is a modern sports sentiment intelligence dashboard that analyzes fan reactions from Reddit and Twitter/X style discussions using interactive visual analytics and sentiment scoring.

---

## ✨ Features

- 🔍 Hashtag-Based Analysis
  - Search any sports hashtag instantly
  - Examples: #RCB, #CSK, #Arsenal, #NBAFinals

- 📊 Real-Time Sentiment Dashboard
  - Positive / Negative / Neutral breakdown
  - Average compound sentiment score
  - Source-wise comparison

- 💬 Fan Comment Explorer
  - Reddit-style and Twitter/X-style comments
  - Engagement metrics (likes, shares)
  - Confidence scoring

- 📈 Interactive Visualizations
  - Sentiment distribution charts
  - Source comparison graphs
  - Engagement vs sentiment analytics

- 🎭 Emotion Detection
  - Excited
  - Angry
  - Proud
  - Frustrated
  - Neutral
  - Happy

- 🧠 AI Insights
  - Automatic sentiment summaries
  - Trend detection
  - High-intensity reaction analysis
  - Sarcasm detection support

- 🎨 Modern Cyberpunk UI
  - Neon-glow dark theme
  - Responsive layout
  - Smooth animations
  - Interactive components
